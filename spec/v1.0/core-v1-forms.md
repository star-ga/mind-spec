# Core v1 Forms

This chapter lists forms of the surface grammar ([`grammar-syntax.ebnf`](./grammar-syntax.ebnf),
[`grammar-lexical.ebnf`](./grammar-lexical.ebnf)) with the status of each form in Core v1. It adds no rule:
the status of a form follows from the grammar and from the normative chapters that the table links. If this
table and the grammar or a normative chapter differ, the grammar and the chapter decide.

- **Core v1**: the grammar derives the form, does not mark it, and no normative sentence forbids it.
- **Core v1 refuses**: a normative sentence forbids the form, whether the grammar derives it or not. A
  conforming implementation MUST refuse it.
- **Not in Core v1**: the grammar derives the form and marks it "NOT IN CORE v1". A conforming implementation
  refuses it or documents it as an extension.
- **Extension**: the grammar does not derive the form and no normative sentence forbids it. Core v1 neither
  requires it nor forbids it. A program that uses it is not a Core v1 program.
- **Open**: the grammar derives the form and no sentence of this specification gives it a meaning.

**Reference verdict (informative).** The mark "reference gap" after a status records that the reference
compiler v0.10.4 does not yet follow the status, the mark "reference conforms" records that it follows the
status for the sources measured, and the words in parentheses say what was measured. The release binary was run
on 2026-11-25 with `mindc check --no-fmt --no-lint` on each probe source, with `mindc build --backend native`
where the mark names the native backend, with `mindc build --backend mlir` where the mark names the MLIR backend,
and with a run of the image where the mark names an image. The rows of
[Forms of the grammar decisions](#forms-of-the-grammar-decisions) were measured on 2026-11-26 in the same way; each names
its probe. A gap is work for the compiler; it
does not change the status. A row without a mark makes no claim about the reference.

## Forms of the grammar decisions

This table has one row for each form that the decisions DN-22 to DN-88 of
[Decision Notes, Part 3](../../design/rfcs/decision-notes-3.md) decide. The status is the status that the decision
gives; the chapters that the decision names state the rule. "Reference pending" records that the reference compiler
v0.10.4 does not yet follow the decided status; "reference conforms" records that it follows it for the probe. The
probe ids with the prefix `e3_` were measured on 2026-11-26 with the release binary (`mindc check --no-fmt --no-lint`,
then `mindc build --backend native` and a run of the image when the check accepts); the other probe ids are the
measurements that the decision note cites.

**Migration (DN-88).** One tool rewrites the mechanical changes of these decisions (numeric suffixes, terminators,
tensor spellings, type names, arm commas, precedence parentheses, module separators): the formatter with a migration
mode. A decided form that needs a rewrite of existing sources is enforced by the reference only in a release that
ships this tool, so the rows below stay "reference pending" until that release and the front end that enforces them.
